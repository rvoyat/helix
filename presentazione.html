Ambito preferito
🔑

Session Token (256-bit)

Ogni sessione genera un token crittograficamente sicuro via secrets.token_hex(32). Salvato in localStorage, inviato come Bearer header.

🔒

Password SHA-256

Le password non sono mai salvate in chiaro. Hash SHA-256 in users.json. Nessuna dipendenza da servizi esterni di autenticazione.

🛡️

Auth Middleware Globale

Ogni richiesta al backend passa attraverso il middleware di autenticazione. Solo /health e /auth/login sono pubblici.

🚫

Role-based Authorization

Rotte admin (settings LLM, gestione utenti, creazione ambiti) bloccate a livello API con HTTP 403 per i guest.
